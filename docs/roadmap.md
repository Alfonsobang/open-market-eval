## Public success criteria

- External contributors can run one task in under 15 minutes.
- Every task has a public source, information cutoff, deterministic or independently reviewable output, and documented rights.
- Results are reproducible from committed artifacts without private data.
- At least two different agent implementations can run the same task contract.

## Explicit non-goals

- Brokerage execution, portfolio automation, stock recommendations, or price targets.
- Claims of market-beating performance from synthetic, leaked, or hindsight-exposed data.
- Publishing private company data, real user data, subscription-only corpora, or proprietary workflows.

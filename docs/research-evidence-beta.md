# Research Evidence Audit beta

The v0.6 beta needs independently designed packets, not applause or synthetic volume.

## Useful submissions

- a false positive where a valid point-in-time packet is blocked;
- a missed provenance defect with a concrete repair rule;
- a financial-search concept that the schema cannot express;
- a minimal, sanitized packet from a real research pattern.

Use the [structured feedback form](https://github.com/Alfonsobang/open-market-eval/issues/new?template=research-packet-feedback.yml). Do not submit strategy code, account information, credentials, licensed report text, private company data, real user data, or proprietary workflow details.

## Acceptance bar

An accepted case must be independently understandable, safe to publish, deterministic enough to test, and useful beyond one model or framework. Every new finding code needs a clean negative control.

## Beta exit criteria

The beta remains open until five independently prepared, sanitized packets have been reviewed and every accepted defect has a regression test. Counts will be updated only from public issues or merged pull requests.
